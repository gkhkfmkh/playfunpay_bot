# playfunpay — Telegram bot

## 1. Установка
Установи Python 3.10+.
Открой терминал в папке проекта и выполни:

```bash
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## 2. Создание бота
1. Открой Telegram и найди `@BotFather`.
2. Отправь `/newbot`.
3. Задай имя и username бота.
4. Скопируй токен.
5. Переименуй `.env.example` в `.env` и вставь токен в `BOT_TOKEN`.

## 3. Узнать свой Telegram ID
Напиши `@userinfobot` и скопируй свой числовой ID.
Вставь его в `ADMIN_IDS` в `.env`.

## 4. Запуск
```bash
py bot.py
```
Открой своего бота и отправь `/start`.
Для панели администратора отправь `/admin`.

## 5. Настройка приватного канала
1. Создай приватный Telegram-канал.
2. Добавь бота в канал администратором.
3. Дай ему право приглашать пользователей (создавать ссылки-приглашения).
4. Узнай ID канала. Можно переслать сообщение из канала боту, который показывает ID чатов, либо использовать собственного диагностического бота.
5. В личном чате с ботом выполни `/setchannel -1001234567890` (замени на реальный ID).

## 6. Настройки из Telegram
- `/setprice 500` — цена (вводи свою валюту и цену в описании/инструкции, бот пока показывает просто число).
- `/setdescription Текст описания` — описание канала.
- `/setpayment Твои реквизиты и инструкция` — инструкции оплаты.
- `/setdays 30` — длительность доступа в днях.
- `/addtheme Название темы` — добавить тему.
- `/broadcast Текст` — рассылка пользователям.
- `/giveaccess 123456789 30` — выдать доступ вручную.
- `/stats` — статистика.

## Важно
- Ручная проверка оплаты означает, что администратор должен проверить поступление денег в своём банке/платёжном сервисе. Скриншот сам по себе не доказывает оплату.
- Не отправляй токен бота другим людям и не публикуй `.env`.
- При окончании срока бот пытается удалить пользователя из канала (для этого ему нужны права блокировать участников). Для стабильной работы 24/7 нужен постоянно работающий компьютер или хостинг.
- Перед запуском для реальных покупателей проверь все сценарии на тестовом аккаунте.
- Ежедневная публикация в этой базовой версии рассылает тему пользователям бота; она не публикует автоматически в канал.
- Этот проект — стартовая версия. Для реального магазина стоит дополнительно добавить журнал действий администратора, постраничный каталог, полноценный редактор тем и более строгую проверку подписок.
